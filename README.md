# Javies Photography Studio

Official website for **Javies Photography Studio** — Accra, Ghana.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- next/image

## Pages

- `/` — Home (hero, featured work, services preview, booking)
- `/services` — Services & packages
- `/gallery` — Photo gallery
- `/about` — About

## Development

```bash
npm install
npm run dev
```

## Production

## Booking email (Resend)

1. Create a Resend account and API key
2. Copy `.env.example` to `.env.local` and fill:

```
RESEND_API_KEY=re_...
JAVIES_EMAIL=client@email.com
BOOKING_FROM_EMAIL="Javies Photography Studio <onboarding@resend.dev>"
```

3. Add the same variables in the Vercel project → Settings → Environment Variables
4. For production, verify a domain in Resend and set `BOOKING_FROM_EMAIL` to that domain

Never commit `.env` / `.env.local`. Never use `NEXT_PUBLIC_` for the API key.

## Gallery

Full client portfolio is generated by:

```bash
node scripts/import-gallery.js
```

This imports unique photos from the client folder into `public/images/gallery/` and writes `src/lib/gallery-data.ts`.
