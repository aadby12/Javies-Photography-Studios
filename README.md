# Javies Photography Studio

Official website for **Javies Photography Studio** — Accra, Ghana.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- next/image

## Pages

- `/` — Home (hero, featured work, services preview, booking)
- `/services` — Services & packages
- `/gallery` — Photo gallery
- `/about` — About

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
